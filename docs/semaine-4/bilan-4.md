## Constats utiles — EF-32 et EF-33

| Cas à vérifier | Test existant et assertion utile | Manque confirmé ou constat écarté |
|---|---|---|
| Un étudiant peut candidater à une offre publiée avec un message facultatif. | `backend/tests/applications.test.ts` vérifie la réponse `201`, le message trimé et le statut `IN_PROGRESS`, ainsi que le cas sans message (`message: null`). | Constat écarté : le parcours nominal est couvert. |
| Une deuxième candidature active pour la même offre est refusée, mais une nouvelle candidature est possible après un retrait. | `applications.test.ts` vérifie `409 APPLICATION_EXISTS`, puis le retrait suivi d’une nouvelle création en `201`. `backend/tests/db/constraints.test.ts` vérifie aussi la contrainte d’unicité. | Constat écarté : le comportement métier et la contrainte SQLite sont testés. |
| Une offre non publiée ou inexistante ne doit pas accepter de candidature. | Le cas d’une offre non publiée est testé avec `409 OFFER_NOT_PUBLISHED`. Aucun test ne vérifie une offre inexistante. | Manque confirmé : ajouter un test `POST /applications` avec un `offerId` inexistant et vérifier `404 NOT_FOUND`. |
| Seuls les étudiants peuvent consulter, créer ou retirer une candidature. | `applications.test.ts` vérifie uniquement que l’administrateur ne peut pas consulter les candidatures (`403`). | Manque confirmé : tester également un administrateur et un contact sur `POST`, ainsi qu’un contact sur `GET` et `DELETE`. |
| Un étudiant ne peut pas retirer la candidature d’un autre étudiant et ne voit que ses propres candidatures. | Le dépôt filtre les lectures et retraits par `studentId`, mais aucun test explicite ne vérifie l’isolation entre deux étudiants. | Manque confirmé : ajouter un test de consultation avec deux étudiants et un test de retrait d’une candidature appartenant à un autre étudiant. |
| Les corps et paramètres invalides sont rejetés avec le bon code d’erreur. | Un test vérifie un message de plus de 1000 caractères et un `offerId` invalide dans le scénario de validation. | Constat partiellement écarté : compléter avec corps non objet, message non textuel, identifiant de retrait invalide et offre inexistante. |
| Les candidatures sont affichées dans les quatre statuts et peuvent être retirées depuis l’interface. | `frontend/tests/ApplicationsPage.test.tsx` vérifie les quatre libellés français et le retrait suivi du rechargement. | Constat écarté pour le parcours nominal ; les erreurs de chargement, le contenu vide, le `401` et l’échec du retrait restent à tester. |
